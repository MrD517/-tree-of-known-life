# Tree of Known Life / 生命系統樹

PC・スマートフォン対応のインタラクティブ生命分類・系統樹ビューアです。

## GitHub Pages
このリポジトリの `main` ブランチ `/ (root)` を GitHub Pages の公開元に設定してください。

- エントリーポイント: `index.html`
- Jekyll 無効化: `.nojekyll`
- Catalogue of Life / ChecklistBank API をブラウザから読み込みます
- 閲覧にはインターネット接続が必要です

## 主な機能
- 分類階層を枝として展開
- 和名・英名・学名で検索
- 和名・カタカナ英名・英名・学名の表示
- 分岐年代が文献上扱える主要ノードには年代注釈
- PC / iPhone 等のスマートフォンに対応

## 注意
Catalogue of Life の分類上の親子関係は、すべての節点で分子系統学的な分岐点そのものを意味するわけではありません。
年代不明の節点には推定値を捏造せず、未割当として表示します。
